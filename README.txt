SOPORTE360 - Gestión técnica, inventario, caja y ventas

CÓMO ABRIR
1. Descomprima la carpeta.
2. Abra index.html con Google Chrome o Microsoft Edge.
3. Los datos se guardan en el navegador de esa computadora mediante localStorage.

MÓDULOS
- Configuración de empresa, RUC, datos, logo y colores.
- Vista previa del logo y ampliación al hacer clic.
- Apertura/cierre y movimientos de caja.
- Clientes.
- Equipos y órdenes de trabajo.
- Punto de reparación dentro de Equipos: repuestos del inventario + mano de obra.
- Al finalizar una reparación: descuenta stock, marca el equipo como Reparado, registra ingreso en caja y genera factura interna.
- Productos e inventario.
- Ventas: únicamente venta directa de productos.
- Historial de facturas de ventas y reparaciones.
- Diseño profesional para impresión de factura interna y orden de servicio.

IMPORTANTE
Esta versión funciona sin servidor y sin base de datos externa. No constituye facturación electrónica autorizada por el SRI. Para uso comercial con comprobantes tributarios electrónicos se requiere integrar el sistema con los requisitos vigentes del SRI y una base de datos/servidor.
